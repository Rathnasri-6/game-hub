# Rathnasri's Game Hub 🎮

Welcome to my **Multi-Game Hub** project!  
This repository contains a collection of fun mini-games built with HTML, CSS, and JavaScript.

## Games Included
- Tic Tac Toe
- Memory Card
- Snake Game
- 2048
- Sudoku

## How to Play
1. Open the [Game Hub](https://yourusername.github.io/game-hub) in your browser.
2. Choose a game from the menu.
3. Play and enjoy!

## Features
- Multiple games in one hub
- Simple design and easy navigation
- "Back to Menu" button in every game
- GitHub Pages deployment
